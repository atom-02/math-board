# 수학 전자칠판

수학 수업용 웹 전자칠판입니다. 설치 없이 크롬 등 브라우저에서 열어 쓰고, 마우스·터치·스타일러스 펜을 지원합니다. 서버나 로그인이 없고 모든 계산은 브라우저 안에서 이루어집니다.

## 기능
- 필기(펜, 형광펜, 지우개), 직선·화살표·사각형·원·삼각형, 입체도형(육면체·원기둥·원뿔·구)
- 확대·축소·이동, 실행 취소/다시 실행, 자동 저장, 파일(.json)·이미지(.png) 저장
- 좌표축·격자, 라디안/도 단위, 함수 그래프
  - 이차곡선(원·타원·포물선·쌍곡선), 다항·유리·무리·지수·로그·삼각·절댓값·구간별 함수
  - 점근선 표시, 접선(기울기·접점·곡선 밖의 점), 극값·변곡점, 정적분·넓이 색칠

## 사용
`index.html` 한 파일로 동작합니다. GitHub Pages로 배포하거나 파일을 내려받아 브라우저에서 열면 됩니다.
